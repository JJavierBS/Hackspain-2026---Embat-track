# mobile

Expo + expo-router. Part of the HackSpain 2026 template — see the root
`../README.md` and `../CHEATSHEET.md`.

Runs through Expo Go on your phone (no Xcode or Android SDK on this
machine). Scan the QR code `make mobile` prints, from the repo root.

```
make ip && make mobile   # from the repo root
```
